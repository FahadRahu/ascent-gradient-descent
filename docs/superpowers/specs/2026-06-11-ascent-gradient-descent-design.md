# ASCENT — Design Spec (pointer)

The canonical, approved design for this project lives in **[`/PRD.md`](../../../PRD.md)** at the repository root, per the project owner's request to name it `PRD.md`.

That document is the single source of truth and contains:

- Vision & positioning (the rigorous + beautiful + playful intersection)
- Goals / non-goals, audience & device targets
- Functional requirements (two hero modes, 9 optimizers, landscapes, math engine, UI/UX)
- The locked "Cinematic Dark" visual design system (palette, colormaps, trail colors, bloom/tone-map recipe, hero beat)
- The "HD / rendered" rendering recipe
- The ambient swarm spec
- Architecture (R3F two-channel state, simulation loop, module boundaries)
- Performance budget & adaptive quality tiers
- Accessibility
- Phased milestones (M0–M4), success metrics, risks
- Fact-checked source references and a decision log

**Status:** approved. **Next step:** implementation planning (a future session), starting from the milestone breakdown in PRD.md §11.

Branches: `legacy` preserves the original implementation; `main` is the new build.
